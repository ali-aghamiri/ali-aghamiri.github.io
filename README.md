# Academic website — Seyyed Ali Aghamiri

Source for [ali-aghamiri.github.io](https://ali-aghamiri.github.io/), a static academic portfolio with research, publications, teaching, selected public code, and a downloadable CV.

The site uses plain HTML, CSS, and a few lines of JavaScript. It requires no build step. GitHub Pages publishes the `main` branch from the repository root.

## Update

- Edit `index.html` for research, publication, or project updates.
- Replace `assets/Seyyed-Ali-Aghamiri-CV.pdf` when the CV changes.
- Edit `assets/styles.css` for visual changes.

Publication status is intentionally stated as it appears on the CV; the submitted manuscript is not presented as published. Only publicly accessible project repositories are linked.
