# Seyyed Ali Aghamiri — academic website

Source for [ali-aghamiri.github.io](https://ali-aghamiri.github.io/), a single-page academic profile with research, publications, education, selected projects, teaching, and a downloadable CV.

The site uses plain HTML and CSS, with no build step. GitHub Pages publishes the `main` branch from the repository root.

- Update `index.html` for academic content and links.
- Update `assets/styles.css` for presentation.
- Replace `assets/Seyyed-Ali-Aghamiri-CV.pdf` when the CV changes.

Publication status is stated explicitly; the submitted manuscript is not described as published. Only verified public projects are featured.
